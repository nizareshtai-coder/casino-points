# Casino Points

A small casino-style web app where players use points instead of real money.

## Features
- Slots game
- Point balance system
- Responsive UI
- Backend API with Express

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the backend:
   ```bash
   npm run server
   ```

3. Start the frontend:
   ```bash
   npm run dev
   ```

4. Open in browser:
   - Frontend: http://localhost:5173
   - Backend: http://localhost:4000

## Project structure

- `src/` — frontend React app
- `server/` — backend Express API
